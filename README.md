# ☕ AADHYA FAST FOOD AND CAFE MANAGEMENT SYSTEM

A modern Cafe Management System built using React and JavaScript.

This project helps manage:
- Orders
- Billing
- Attendance
- Payroll
- Staff Roles
- Customer Management
- Daily Reports

---

# 🚀 Features

✅ Admin Dashboard  
✅ Staff Login System  
✅ Attendance Management  
✅ Payroll System  
✅ Customer Role  
✅ Order & Billing System

# 📦 Installation

## 1. Clone Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

## 2. Open Project Folder

```bash
cd project-name
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Run Project

```bash
npm run dev
```

OR

```bash
npm start
```

---

# 🌐 Open in Browser

After running, open:

```bash
http://localhost:5173
```

OR the URL shown in terminal.
